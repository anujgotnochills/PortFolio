# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Search engine setup

The production URL is configured in `src/lib/seo.ts`. Update it when moving to a custom domain; the canonical URL, sitemap, robots rules, social metadata, and structured data use this value.

- `/sitemap.xml` is generated by `src/app/sitemap.ts`. The portfolio currently has one page; section links such as `#projects` are not separate sitemap entries. Add new public pages here when they are created. Only add a last-modified date when it reflects a real content update.
- `/robots.txt` is generated by `src/app/robots.ts`, allows crawling, and points to the sitemap.
- `src/app/layout.tsx` supplies search metadata and social cards. The homepage canonical URL is set in `src/app/page.tsx`.
- `/opengraph-image` generates the 1200 × 630 share preview using the existing portrait. Both Open Graph and Twitter cards use it.
- The homepage includes `WebSite`, `ProfilePage`, and `Person` JSON-LD based on the visible profile and social links.
- Keep `public/googled5553772b1dc10a3.html` in place to retain Google Search Console ownership verification.

After deploying:

1. Open `/robots.txt`, `/sitemap.xml`, and the Google verification file on the production domain and confirm they load.
2. Complete ownership verification in Google Search Console, then submit `https://anujonedit-portfolio.vercel.app/sitemap.xml` under **Sitemaps**.
3. Inspect the homepage using Search Console's URL Inspection tool, run a live test, and request indexing.
4. Check structured data with Google's Rich Results Test and Schema.org's validator. Check mobile performance with PageSpeed Insights. Indexing, rankings, and enhanced search results are determined by search engines.

References: [Next.js metadata files](https://nextjs.org/docs/app/api-reference/file-conventions/metadata), [Google sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [Google profile markup](https://developers.google.com/search/docs/appearance/structured-data/profile-page), and [Google site names](https://developers.google.com/search/docs/appearance/site-names).
